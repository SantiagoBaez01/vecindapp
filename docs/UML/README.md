## 📐 Flujo de trabajo para el Diagrama de Clases (UML)

1. **Para ir actualizándolo:** A medida que avancemos y creemos los Controladores y Servicios, abrir el archivo `docs/diagrama_clases.md` y agregar las líneas de texto correspondientes al código Mermaid.
2. **Para previsualizarlo en VS Code:** Se recomienda instalar la extensión **"Markdown Preview Mermaid Support"** en Visual Studio Code, se puede ir viendo cómo se dibuja el gráfico en tiempo real mientras se escribe el código.
3. **Para exportarlo a PNG al final:** Cuando el proyecto esté terminado y si necesitamos poner la imagen fija en el informe final o en el README, copiar el bloque de código, pegarlo en la página web **[Mermaid Live Editor](https://mermaid.live/)** y hacer clic en el botón *Save as PNG*.
